# Mapa de Conexões do Sul de Minas

Aplicação institucional para cadastro e visualização de participantes por município.

## Configuração rápida

1. Abra `config.js`.
2. Substitua os dois textos pelos dados públicos do Supabase.
3. Publique com GitHub Pages.

Nunca coloque senha do banco, `service_role`, `sb_secret_` ou chave secreta neste repositório. Use somente a URL e a Publishable Key (`sb_publishable_`).
